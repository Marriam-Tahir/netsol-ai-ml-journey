# Titanic Data Analysis 🚢

This project focuses on exploring and understanding the **Titanic dataset** using Python and data analysis libraries.

## 📌 Objective

The goal of this analysis is to explore the dataset, understand the available features, identify patterns in the data, and prepare the data for further Machine Learning work.

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## 📊 Dataset

The analysis works with Titanic passenger data and explores features such as:

- Survived
- Pclass
- Sex
- SibSp
- Parch
- Fare
- Embarked
- FamilySize

## 🔎 Analysis

The notebook includes:

- Data exploration
- Data understanding
- Feature analysis
- Data preprocessing
- Visualization
- Pattern exploration

## 📁 File

`Titanic_Data_Analysis.ipynb`
